# 考公学习库

这是一个公开的考公学习网站，内容来自 `.study/` 目录，网站使用 VitePress 生成。

## 常用命令

```bash
npm run sync
npm run dev
npm run build
npm run preview
```

## 发布信息

- GitHub 仓库：https://github.com/cfy1126/kaogong-study-site
- Netlify 网站：https://kaogong-study-site.netlify.app
- Netlify 构建命令：`npm run build`
- Netlify 发布目录：`website/.vitepress/dist`

继续学习时，先更新 `.study/`，再运行 `npm run sync` 或直接运行 `npm run build`。
