# Study Second Brain

用于把考公学习内容沉淀到当前项目的 `.study/` 目录。目标很简单：下次学习前先读旧记录，不从零开始。

## 目录

```text
.study/
  dashboard.md          # 第二大脑首页，每次开始学习先读
  daily/                # 每日学习记录
  weekly/               # 每周总结
  monthly/              # 每月总结
  mindmaps/             # Markdown 脑图和掌握状态
  mistakes/             # 错题、错因、易错规则
  cards/                # 知识点图片记忆卡片
  templates/            # 记录模板
```

## 触发场景

开始学习类：
- "开始学习"
- "继续学习"
- "今天学什么"
- "安排今日复习"
- "根据第二大脑给我计划"

收尾记录类：
- "学习收尾"
- "记录今天学习"
- "更新第二大脑"
- "写学习汇报"
- "复盘今天"

维护类：
- "更新脑图"
- "整理错题"
- "生成周总结"
- "生成月总结"

## 学习开始流程

1. 读取 `.study/dashboard.md`。
2. 读取最近 3 条 `.study/daily/*.md`，没有就说明暂无历史记录。
3. 根据 dashboard 的当前主攻模块，读取对应文件：
   - 行测：`.study/mindmaps/行测脑图.md`
   - 申论：`.study/mindmaps/申论脑图.md`
   - 错题：`.study/mistakes/对应模块错题.md`
4. 输出今日计划，默认按 2 小时安排：
   - 考点理解 35 分钟
   - 核心掌握 35 分钟
   - 题型训练 35 分钟
   - 笔记复盘 15 分钟
5. 每天只建议一个小考点。不要同时安排多个新考点。

## 学习收尾流程

1. 从用户描述中提取今天的学习内容。
2. 如果信息不足，先问最多 3 个问题：
   - 今天学了哪个模块和考点？
   - 做了多少题，错了几题？
   - 今天最主要的错因是什么？
   - 如果练习题来自本次对话，由 Codex 自动统计题量和错题数；不要再让用户手动数题。
3. 写入 `.study/daily/YYYY-MM-DD.md`。
4. 更新 `.study/dashboard.md`：
   - 最近一次学习
   - 当前待办
   - 易错考点
   - 下次建议
5. 更新对应脑图文件中的状态。
6. 有错题或错因时，更新 `.study/mistakes/对应模块错题.md`。
7. 生成一张知识点图片记忆卡片，保存到 `.study/cards/YYYY-MM-DD-考点名.png`。
8. 如果是周末，提醒可生成周总结；如果是月底，提醒可生成月总结。

## 知识点图片记忆卡片

学习收尾并经用户确认写入后，默认生成一张图片记忆卡片。

卡片要求：

- 风格：简约、专业、自然，配色克制，版面干净。
- 内容：只放本次学习的核心概念、公式、易错点和下次提醒。
- 字数：少而清楚，适合零基础复习，不堆大段文字。
- 文件名：`.study/cards/YYYY-MM-DD-考点名.png`，考点名尽量短。
- 用途：辅助复习和展示，不能替代 Markdown 脑图和每日记录。
- 如果包含 IPA 音标、数学符号或其他专业符号，生成后提醒用户校对准确性。

## 状态标签

只使用这些状态，避免笔记混乱：

```text
未学
已理解
会做但慢
易错
已掌握
需要二刷
暂时放弃
```

## 写入原则

- 先读再写。不要直接覆盖旧内容。
- 追加为主，必要时只更新 dashboard 的当前状态区。
- 错题不抄长题干，只记录错因、规则和下次做法。
- 脑图用 Markdown，图片只作为展示，不作为唯一知识来源。
- 图片记忆卡片只总结关键点，不承载完整笔记。
- 如果用户没有明确说要写入，涉及学习收尾时先确认。
- 学习收尾时，默认由 Codex 根据本次对话自动统计练习题数量和错题数量；用户只需要补充主观掌握状态。

## 输出风格

输出中文，简洁、清楚、适合初学者。不要写空泛鼓励语。把下一步说具体。
