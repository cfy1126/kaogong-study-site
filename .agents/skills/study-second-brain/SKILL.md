# Study Second Brain

用于把考公学习内容沉淀到当前项目的 `.study/` 目录。目标很简单：下次学习前先读旧记录，不从零开始。

## 目录

```text
.study/
  dashboard.md          # 第二大脑首页，每次开始学习先读
  daily/                # 每日学习记录
  weekly/               # 每周总结
  monthly/              # 每月总结
  mindmaps/             # Markdown 脑图和掌握状态
  mistakes/             # 错题、错因、易错规则
  cards/                # 知识点图片记忆卡片
  templates/            # 记录模板
```

## 触发场景

开始学习类：
- "开始学习"
- "继续学习"
- "今天学什么"
- "安排今日复习"
- "根据第二大脑给我计划"

收尾记录类：
- "学习收尾"
- "记录今天学习"
- "更新第二大脑"
- "写学习汇报"
- "复盘今天"

维护类：
- "更新脑图"
- "整理错题"
- "生成周总结"
- "生成月总结"

## 学习开始流程

1. 读取 `.study/dashboard.md`。
2. 读取 `.study/plan-2027-guokao.md`，确认当前阶段、最近硬截止日期和本阶段验收线。官方笔试日期公布后，以官方日期替换计划锚点并重新倒排。
3. 读取最近 3 条 `.study/daily/*.md`，没有就说明暂无历史记录。
4. 根据 dashboard 的当前主攻模块，读取对应脑图和错题文件：
   - 资料分析：`.study/mindmaps/行测脑图.md`、`.study/mistakes/资料分析错题.md`
   - 判断推理：`.study/mindmaps/行测脑图.md`、`.study/mistakes/判断推理错题.md`
   - 言语理解：`.study/mindmaps/行测脑图.md`、`.study/mistakes/言语理解错题.md`
   - 申论：`.study/mindmaps/申论脑图.md`、`.study/mistakes/申论错题.md`
   - `.study/mistakes/行测错题.md` 只作索引，不在里面记录错题正文。
5. 输出今日计划时，先说明“当前阶段→最近截止日期→今天任务→今天验收”，再按 2 小时安排：
   - 考点理解 35 分钟
   - 核心掌握 35 分钟
   - 题型训练 35 分钟
   - 笔记复盘 15 分钟
6. 当天任务按以下顺序选择：
   - 最近截止日期中已逾期或即将逾期的任务；
   - dashboard “下次建议”中的二刷或限时验收；
   - 当前阶段尚未完成的高优先级考点；
   - 其他新考点。
7. 每天只建议一个新小考点，不同时安排多个新考点。旧题复测不算新考点。
8. 每次学习留 15 至 20 分钟复测旧考点。若 dashboard 的“下次建议”或当前主攻考点标记为“需要二刷”，本次先二刷，不开新考点；其他模块的二刷按周复盘安排，不打断当前小考点。

## 学习收尾流程

1. 从用户描述中提取今天的学习内容。
2. 如果信息不足，先问最多 3 个问题：
   - 今天学了哪个模块和考点？
   - 做了多少题，错了几题？
   - 今天最主要的错因是什么？
   - 如果练习题来自本次对话，由 Codex 自动统计题量和错题数；不要再让用户手动数题。
3. 写入 `.study/daily/YYYY-MM-DD.md`。
4. 更新 `.study/dashboard.md`：
   - 最近一次学习
   - 当前待办
   - 易错考点
   - 下次建议
   - 最近阶段目标的完成证据（只有达到计划验收线才勾选）
5. 更新对应脑图文件中的状态。
6. 有错题或错因时，按模块更新唯一的错题正文文件：
   - 资料分析写入 `.study/mistakes/资料分析错题.md`
   - 判断推理写入 `.study/mistakes/判断推理错题.md`
   - 言语理解写入 `.study/mistakes/言语理解错题.md`
   - 申论写入 `.study/mistakes/申论错题.md`
7. 生成一张知识点图片记忆卡片，保存到 `.study/cards/YYYY-MM-DD-考点名.png`。
8. 如果是周末且本周信息足够，写入 `.study/weekly/YYYY-WNN.md`；信息不足时再询问。月底可提醒生成月总结。

## 知识点图片记忆卡片

学习收尾并经用户确认写入后，默认生成一张图片记忆卡片。

卡片要求：

- 风格：简约、专业、自然，配色克制，版面干净。
- 内容：只放本次学习的核心概念、公式、易错点和下次提醒。
- 字数：少而清楚，适合零基础复习，不堆大段文字。
- 文件名：`.study/cards/YYYY-MM-DD-考点名.png`，考点名尽量短。
- 用途：辅助复习和展示，不能替代 Markdown 脑图和每日记录。
- 如果包含 IPA 音标、数学符号或其他专业符号，生成后提醒用户校对准确性。

## 状态标签

只使用这些状态，避免笔记混乱：

```text
未学
已理解
会做但慢
易错
已掌握
需要二刷
暂时放弃
```

## 状态判定

- 当天理解规则并能完成同类题，记为“已理解”。当天全对也不直接记为“已掌握”。
- 能做但速度慢、需要提示或依赖刚讲完的记忆，记为“会做但慢”。
- 同类错误反复出现，记为“需要二刷”；下一次先二刷，不开新考点。
- “已掌握”必须同时满足：
  - 学完 3 至 7 天后完成复测；
  - 混合题正确率不低于 80%；
  - 没有重复旧错因；
  - 能独立说出解题入口；
  - 行测达到合理限时，申论能独立完成一次限时作答。
- 每周复盘根据复测结果升降状态。每日记录保留当时判断，不回改；当前状态以 Markdown 脑图为准。

## 每周复测

- 每周至少做一次模块混合小测。
- 小测通过标准：正确率不低于 80%，没有明显超时，没有重复旧错因，并能说清解题入口。
- 小测通过后可以继续新考点；未通过则把对应考点标为“需要二刷”，下一次只安排二刷。
- 周总结只保留本周学习、复测结果、重复错因、距离最近硬截止日期的未完成项，以及下周必须二刷的一个考点。

## 写入原则

- 先读再写。不要直接覆盖旧内容。
- 追加为主，必要时只更新 dashboard 的当前状态区。
- 错题不抄长题干，只记录错因、规则和下次做法。
- 同一条错因只保存在一个模块错题文件中，不能同时写入模块文件和 `行测错题.md`。
- 脑图用 Markdown，图片只作为展示，不作为唯一知识来源。
- 图片记忆卡片只总结关键点，不承载完整笔记。
- 如果用户没有明确说要写入，涉及学习收尾时先确认。
- 学习收尾时，默认由 Codex 根据本次对话自动统计练习题数量和错题数量；用户只需要补充主观掌握状态。

## 输出风格

输出中文，简洁、清楚、适合初学者。不要写空泛鼓励语。把下一步说具体。
