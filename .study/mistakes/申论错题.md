# 申论错题与错因

## 记录格式

```markdown
### YYYY-MM-DD - 题型

- 题型：
- 错因：
- 正确规则：
- 下次先做：
```

## 错题记录

### 2026-06-27 - 材料阅读 / 归纳概括

- 题型：做法类归纳概括
- 错因：前期容易漏掉配合主体、服务对象和对接对象；有一次只写前半段，漏掉机制、宣传、反馈等后半段信息。
- 正确规则：主体包括做事者、被服务者、配合者和渠道对象；做法类题目要逐个检查分号后的动作，特别留意机制、台账、反馈、宣传、培训、整改。
- 下次先做：先圈主体和动作，再合并同类信息，最后写“概括词 + 材料要点”。
