# 申论错题与错因

## 记录格式

```markdown
### YYYY-MM-DD - 题型

- 题型：
- 错因：
- 正确规则：
- 下次先做：
```

## 错题记录

### 2026-06-27 - 材料阅读 / 归纳概括

- 题型：做法类归纳概括
- 错因：前期容易漏掉配合主体、服务对象和对接对象；有一次只写前半段，漏掉机制、宣传、反馈等后半段信息。
- 正确规则：主体包括做事者、被服务者、配合者和渠道对象；做法类题目要逐个检查分号后的动作，特别留意机制、台账、反馈、宣传、培训、整改。
- 下次先做：先圈主体和动作，再合并同类信息，最后写“概括词 + 材料要点”。

### 2026-06-28 - 归纳概括

- 题型：问题类归纳概括
- 错因：个别概括词超出材料原意，把“家属认知不足、配合不积极”写成“家属不信任”。
- 正确规则：问题类概括要忠于材料，采用“问题标签 + 具体表现”；不能凭感觉加重判断。
- 下次先做：先判断材料说的是问题、原因还是表现，再落笔写“存在什么问题”。

### 2026-06-29 - 归纳概括

- 题型：问题类、原因类归纳概括
- 错因：问题题中个别标签带入推断；原因题前期容易照抄材料，或把“接待能力不足”和“产品特色不明显”等不同原因合在一条里。
- 正确规则：问题题写“现在有什么不好”，原因题写“为什么会这样”；同类信息合并，不同类原因拆开。
- 下次先做：先看题目问“问题”还是“原因”，再给每条要点加上准确标签。

### 2026-07-05 - 归纳概括

- 题型：问题原因混合判断
- 错因：有时把问题表现直接写成原因，比如把“兴趣不高、缺少特色、接送压力大”等结果性表述放进原因栏。
- 正确规则：问题写结果，原因写短板；原因标签要上提成“能力不足、调研不足、标准化不足、配套不足、文化挖掘不足”等表达。
- 下次先做：先圈问题表现，再反问“为什么会这样”，最后检查原因栏里有没有混进问题词。

### 2026-07-08 - 归纳概括

- 题型：问题原因混合判断 / 答案句压缩
- 错因：分类基本稳定，但压缩答案时偶尔漏掉后半句，比如只写“收入不高”，漏掉“参与意愿不强”；个别表达会把材料范围扩大。
- 正确规则：问题句用“问题标签 + 具体表现”，原因句用“短板标签 + 材料依据”；材料只说一分，不写成三分。
- 下次先做：先写完整要点，再压缩成短句，最后检查有没有漏掉结果、原因标签和材料依据。

### 2026-07-14 - 归纳概括

- 题型：问题原因整合 / 限字表达
- 错因：有时把居民反映的问题写进原因栏，比如“种植指导不足”“图书更新慢”；个别原因标签写得过大，比如把具体材料上提成“教学资源不完善”。
- 正确规则：问题写“现在有什么不好”，原因写“为什么会这样”；居民反映的问题表现放问题栏，工作人员解释的短板放原因栏。
- 下次先做：先圈总问题，再分居民反映和工作人员解释，最后排除“下一步、准备、应当”等对策句。

### 2026-07-28 - 提出对策

- 题型：漏点和多余项混合判断
- 错因：看到“收费、价格、补贴”类选项时，容易把材料没提的内容当成主要问题。
- 正确规则：提出对策题只能围绕材料问题写；材料没有说价格、收费、补贴，就不要把它当成主要矛盾。
- 下次先做：先数材料里有几个问题，再逐条对照答案；最后单独检查有没有材料外内容和身份权限问题。

### 2026-07-29 - 提出对策

- 题型：手机复习版综合巩固，含材料边界、身份权限、空话改具体、漏点和多余项判断。
- 错因：看到“居民建议增加咖啡售卖服务”时，误以为材料中出现的建议都能写进主对策；漏点判断时只看到一个漏项，没把材料剩余问题全部对照完。
- 正确规则：材料里出现的信息不一定都是主对策，能解决主要问题的才优先写；漏点题要先数材料问题，再看答案解决了几个。
- 下次先做：先标出材料的真实问题，再判断每条对策对应哪个问题；遇到“居民建议、有人认为、可以增加”这类信息时，先判断是不是主问题。

### 2026-07-29 - 提出对策

- 题型：电脑复习版完整作答，材料边界和漏点判断混合。
- 错因：便民维修点题中，看到“维修人员态度生硬”后写了培训和考核，但漏掉“解释不清维修内容”，没有把一句材料里的两个问题都转成动作。
- 正确规则：一句材料里如果有两个问题，答案也要有两个对应动作；如“态度生硬、解释不清”，要写服务培训，也要写维修前说明项目和费用、维修后说明结果和注意事项。
- 下次先做：先给材料问题编号，再在答案旁边标对应关系；写完检查每个编号有没有被解决。

### 2026-08-10 - 提出对策

- 题型：短材料一句对策与分条表达。
- 错因：乡村旅游题中能写出培训和宣传，但漏掉“村民觉得赚不到钱”对应的收益机制；公益课堂题中一开始把“参与率下降”写成问题编号，没有继续拆成课程重复、授课单一、时间调整等具体原因。
- 正确规则：提出对策题先找具体问题和原因，再写对应动作；“不懂”写培训，“不会”写示范，“赚不到”写收益机制，“不方便”写时间和服务安排。
- 下次先做：先给材料问题编号，确认每个编号都是具体问题；再写对应对策，最后检查有没有漏掉材料后半句。

### 2026-08-13 - 贯彻执行 / 讲话稿

- 题型：讲话稿审题、主体分条和完整正文。
- 错因：内容判断没有出错，但表达中出现称呼重复、笔误和做法表述不够具体；有一处根据“小份餐”自行补入“减少浪费”的目的。完整正文练习没有单独写标题。
- 正确规则：先审“身份、对象、目的、内容”；主体写“概括词 + 材料中的具体做法”，不擅自补目的；题目要求完整讲话稿且未说明“不考虑格式”时，写标题、称谓和正文。
- 下次先做：草稿先列四项审题信息，再按“标题 → 称谓和来意 → 分条主体 → 结尾”写作，最后检查材料边界、具体对象和标点。
